# موقع جمعية صناع المستقبل - الفيوم (The Future Makers)

الموقع الرسمي لجمعية **صناع المستقبل للتنمية بمحافظة الفيوم** (The Future Makers) — نسخة مكررة ومطورة بالكامل ومبنية على هوية جمعية أجيال (Life Makers)، ومخصصة بالكامل لمحافظة الفيوم ونطاق `thefuture-makers.com`.

---

## 🌟 محتويات الموقع والصفحات المنجزة

1. **الصفحة الرئيسية (`/`):**
   - قسم الهيرو التعريفي مع الشعار الجديد وشارات التضامن الاجتماعي.
   - نافذة التحقق الفوري (التحقق من العضوية / التحقق من حالة طلب المساعدة بالرقم القومي).
   - إحصائيات الأثر الميداني بمحافظة الفيوم (+5,400 أسرة مستفيدة، +52 قرية، +950 متطوع).
   - شبكة الخدمات التنموية (تمكين اقتصادي، دعم تعليمي، تدخلات صحية، سكن كريم).
   - أحدث أخبار وفعاليات الفرع بمراكز الفيوم.
   - قنوات التبرع الرسمية (فودافون كاش، الحساب البنكي والآيبان IBAN).
   - الأزرار العائمة للتواصل الفوري عبر واتساب وفيسبوك.

2. **صفحة من نحن (`/about`):**
   - الرؤية والرسالة والقيم التنموية.
   - قسم البيانات التسجيلية الرسمية والترخيص القانوني المعتمد لدى مديرية التضامن الاجتماعي بالفيوم.
   - دعوة الانضمام لفريق العمل التطوعي.

3. **صفحة المشاريع والخدمات (`/projects`):**
   - الحملات والمشاريع الجارية (بطانية الشتاء 2026، كفالة الأيتام، قوافل الرعاية الطبية) مع نسب الإنجاز والمستهدفات.
   - البرامج الرئيسية الأربعة للأثر المستدام.

4. **صفحة دليل الخدمات (`/services`):**
   - تصفح وتبويب كافة الخدمات التنموية حسب التصنيف مع توضيح الفئات المستهدفة وزر التقديم.

5. **صفحة تطوع معنا (`/volunteer`):**
   - زر التقديم الفوري والمباشر عبر واتساب المعتمد.
   - استمارة التسجيل الإلكتروني الكاملة للمتطوعين مع تحديد المركز بالفيوم واللجنة المفضلة.

6. **صفحة طلب مساعدة (`/request-aid`):**
   - معالج إلكتروني تفاعلي متكامل من 3 خطوات (البيانات الأساسية، تفاصيل الحالة، المراجعة والتأكيد).
   - إسناد تلقائي لمراكز الفيوم (الفيوم، سنورس، إطسا، طامية، إبشواي، يوسف الصديق).
   - توليد رقم متابعة رسمي معتمد فور الإرسال.

7. **صفحة تواصل معنا (`/contact`):**
   - بيانات المقر الرئيسي بالفيوم (حي الجامعة)، أرقام الهاتف، البريد الإلكتروني، ومواعيد العمل.
   - نموذج إرسال الرسائل والاستفسارات المباشر.

8. **بوابة تسجيل دخول فريق العمل (`/login`):**
   - واجهة مخصصة لموظفي الفرع والمتطوعين المسجلين لإدارة الحالات.

9. **صفحة الخطأ 404 (`*`):**
   - متطابقة مع التصميم الأصلي مع زر العودة للرئيسية.

## 🚀 التشغيل والتطوير المحلي

```bash
# تثبيت الحزم (تم بالفعل)
npm install

# تشغيل خادم التطوير المحلي
npm run dev

# بناء النسخة الإنتاجية
npm run build

# معاينة النسخة الإنتاجية محلياً
npm run preview
```

---

## 🌐 الرفع على الاستضافة (cPanel / Apache / Shared Hosting)

1. تم إعداد ملفات النسخة الإنتاجية الجاهزة داخل مجلد `dist/`.
2. قم برفع محتويات مجلد `dist` مباشرة إلى مجلد `public_html` في استضافتك (أو عبر FTP / مدير الملفات).
3. ملف `.htaccess` المرفق مع المجلد يقوم تلقائياً بضبط توجيه الروابط (SPA Rewriting) حتى تعمل جميع الصفحات مثل `/about` و `/projects` بدون أي خطأ 404 عند تحديث الصفحة أو الدخول المباشر.
